# NXT AI

NXT AI is a Cloudflare-native AI operating layer built around reliable agent execution, tools, memory, durable tasks, model abstraction, and verification.

## Status

Foundation phase. The repository starts with typed boundaries and real Cloudflare persistence; capabilities are added only when implemented and tested.

## Commands

```bash
npm install
npm run typecheck
npm test
npm run build
```

See `ARCHITECTURE.md`, `DATABASE.md`, and `DEPLOYMENT.md`.
